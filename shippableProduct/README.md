# Shippable product

## Backend

Spring-boot serveren vår er shippable og hostes på:
[pixelart-server.onrender.com](https://pixelart-server.onrender.com/canvas)

## Frontend

React frontenden vår er også shippable og hostes på:
[pixelart-5awn.onrender.com](https://pixelart-5awn.onrender.com/)

## Java klient

Java klienten er semi-shippable. I denne mappen vil du finne en mappe som heter "PixelArtApp", denne må du pakke ut, her vil du finne en .exe fil. Start denne og du vil kjøre appen vår.
Vi fikk dessverre ikke til å kjøre denne med serveren vi hoster, og må kjøre med `http//localhost:8080/canvas`. For å teste persistensen på dette produktet, er det anbefalt å kjøre serveren. For å kjøre serveren lokalt [se her](../README.md#spring-boot-server).
Videre er dette noe vi hadde undersøkt dypere.
