# Shippable product

## Server

Serveren vår er fullstendig shippable og vertes på:

[pixelart-server.onrender.com](https://pixelart-server.onrender.com/canvas)

## React
React frontenden vår er også fullstendig "shippable" denne verter vi på:

[pixelart-5awn.onrender.com](https://pixelart-5awn.onrender.com/)

## Java
Java prosjektet er semi-shippable. I denne mappen vil du finne en mappe som heter "PixelArtApp", her er det en .exe fil som vil kjøre appen vår.

Vi fikk dessverre ikke til å kjøre denne med serveren vi verter. Og må holder kjøre med `http//localhost:8080/canvas`. For å teste persistensen på dette produktet, er det anbefalt å kjøre mvn spring-boot:run for å få persistensen.

Til neste sprint er dette noe vi hadde undersøkt dypere.
