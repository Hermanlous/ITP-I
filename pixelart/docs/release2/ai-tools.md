# Bruk av KI verktøy
Vi benytter oss av ChatGPT og Claude Sonnet 3.5. Det har blitt brukt til å forståelse, lesbarhet og småkodesnutter. Det er verktøy som brukes for effektivitet, og for et ekstra kristisk øye på arbeidet vårt. All kode er grundig lest, forstått og redigert før den er blitt tatt i bruk. Vi har ikke brukt KI, dersom vi ikke forstår hva den genererer.
