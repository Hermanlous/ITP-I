# Parprogrammering

Vi har brukt parprogrammering hyppig for å øke vår effektivitet og forbedre kodekvalitet. Når flere koder sammen brukes det mindre tid på at andre skal sette seg inn i kode. Vi kan dele kunnskap, løse problemer og sørge for slik kodestil over hele prosjektet.
